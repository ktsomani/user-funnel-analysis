# B2B SaaS GTM Pipeline & ICP Analytics

A portfolio project for **GTM, Growth, Product Analyst and Data Analyst** roles.

## Business question
Which customer segments and acquisition channels create the highest-quality pipeline, and where do prospects drop out?

## Stack
Python, SQL, CRM-style funnel analysis, ICP segmentation, sales velocity and static HTML dashboard.

## Dataset
Synthetic CRM dataset with 8,000 leads.

## What this project demonstrates
- Lead → MQL → SQL → Demo → Trial → Closed Won funnel
- Win rate by channel
- ICP segmentation by company size and industry
- ACV and sales-cycle analysis
- Lost-deal reasons
- Decision-oriented GTM recommendations

## Key results
- Closed-won rate: **4.3%**
- Average ACV: **$13,011**
- Average sales cycle: **44 days**
- Best channel hypothesis: **Founder Outbound**
- Best ICP hypothesis: **201+ Services**

Open `dashboard/index.html` for the static dashboard.

## Important
All data is simulated. Results show the analytical workflow and should not be represented as real company performance.
