Featured Case Study

E-commerce user funnel analysis.

A reproducible analytics project showing the full path from raw event data to validated metrics, findings, recommendations and an interactive dashboard.

Python + SQLite + interactive dashboard

Where are users dropping out of the purchase journey?

I modeled an ordered five-stage session funnel — Visit → View Product → Add to Cart → Checkout → Purchase — and validated the SQL output against an independent Python event traversal.

Live dashboard ↗Methodology ↗Findings ↗

All numbers here come from a synthetic dataset. They demonstrate analytical method, not results from a real company.

72.01%visit → product view
32.68%product view → add to cart
70.43%cart → checkout
57.57%checkout → purchase
01

Problem

Identify the biggest conversion losses and which segments deserve deeper investigation.

02

Method

Cleaned event data, deduplicated records, enforced ordered timestamps and built session-level SQL funnels.

03

Finding

The largest proportional loss was at add-to-cart: 5,817 eligible sessions dropped, or 67.32%.

04

Action

Frame product-page friction, mobile checkout and traffic-intent hypotheses as experiments with guardrails.

Data quality

Removed 200 duplicate records and 1 orphan record while keeping an audit trail.

Segmentation

Mobile conversion was 7.83% versus 12.3% on desktop in the simulation — diagnostic, not causal.

Experiment design

Recommendations use a primary metric, guardrails and no uplift claim before testing.
